# Archive

This directory contains historical artifacts from the development of the classification pipeline.

## Contents

-   `initial_prompt_v1.txt`: The very first prompt synthesized by the automated `optimize_prompt.py` pipeline. It served as the baseline for the Refined Prompt used in v2.
-   `optimized_prompt_<timestamp>.txt`: Automatically generated system instructions from `optimize_prompt.py` runs (Jan 2026 onwards).
-   `optimize_run_<timestamp>.json`: Complete Metadata and observations for optimization runs, providing full traceability for prompt generation.
