# Archive

This directory contains historical artifacts from the development of the classification pipeline.

## Contents

-   `initial_prompt_v1.txt`: The very first prompt synthesized by the automated `optimize_prompt.py` pipeline. It served as the baseline for the Refined Prompt used in v2.
-   `initial_results_20251231.csv`: The raw results (Confusion Matrix, predictions, and reasoning) from the first full batch run (1800 samples) using the v2 prompt. This run achieved **84% Recall** and **85% Accuracy**, establishing the project's success.
