# Prompt Improvement Study Documentation

This study aimed to improve the prompts for each class using the training file with 366 observations.
We used an iterative hierarchical approach with 2 levels.

## Level 1: Individual Patterns
We generated detailed descriptions for each of the 366 samples. Results saved to `prompt_study_level_1.csv`.

## Level 2: Consolidated Patterns
We consolidated the descriptions per class. Results saved to `prompt_study_level_2.json`.

## Final Prompt
The resulting system prompt is saved to `refined_prompt.txt`.
